Rivet

Run coding agents on your own machine, each in its own copy of your project, and follow their work from one app in your browser. Rivet uses the agents you already have, with their own logins.

Install

Then run rivet. It opens in your browser and shows what is ready on this machine.

What it does

  • One task, one worktree. Each session gets its own git branch and folder, so agents never write over each other or over you.
  • Claude Code, Codex, or a local model. Pick per thread; switch a session to another agent without losing its history.
  • See every change. Each prompt shows the files it changed; roll a conversation back, with its files, to any turn.
  • Checks before a pull request. Rivet runs your check and tests itself, then pushes and opens the PR; CI failures and review comments go back to the agent.
  • Answer from anywhere in the app. Permission questions, queued messages, forks and branches, all in one place.

What it needs

  • git, and a project in a git repository.
  • At least one agent: Claude Code (claude auth login) or Codex (codex login), or Ollama for local models.
  • Windows, macOS or Linux. The one-line install brings its own Node.js; npx needs Node.js 24.

Desktop app

Prefer an app window? Download it from the latest release. The builds are not signed yet: on Windows choose More info → Run anyway; on macOS run xattr -cr /Applications/Rivet.app once after moving it to Applications.
